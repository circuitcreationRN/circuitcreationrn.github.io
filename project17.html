Arduino UNO LED Chaser

This Arduino UNO LED Chaser project creates multiple running-light effects using 8 LEDs. The LEDs turn ON and OFF in different sequences to produce a colorful chasing animation. This beginner friendly project demonstrates Arduino digital output control, LED sequencing, and basic programming without using complex components.

Components Required

  • Arduino UNO R3
  • 8 × LEDs
  • 8 × 220Ω Resistors
  • Breadboard
  • Jumper Wires
  • Arduino USB Cable
  • OTG Cable
  • Android Phone
  • Arduinodroid App

Circuit Connections

Step 1 – Connect the LEDs

Connect the 8 LEDs on the breadboard in a straight or arranged pattern. Keep the LED polarity correct.

Step 2 – Connect LED Resistors

Connect one 220Ω resistor in series with each LED to limit the current and protect the LEDs.

Step 3 – Connect LED Positive Terminals

Connect the positive leg (anode) of each LED through its 220Ω resistor to Arduino digital pins 2 to 9.

Step 4 – Connect LED Negative Terminals

Connect the negative leg (cathode) of every LED to the Arduino GND.

Step 5 – Connect the Arduino

Connect the Arduino UNO to your Android phone using a USB cable and OTG cable.

Step 6 – Open Arduinodroid

Open the Arduinodroid app, create a new sketch, and paste the LED Chaser code.

Step 7 – Upload the Code

compile and upload the program. After uploading, the LEDs will start running through the programmed effects.

Circuit Explanation

Each LED is connected to a separate digital pin of the Arduino UNO through a 220Ω current-limiting resistor. The Arduino controls the LEDs individually by setting the digital pins HIGH or LOW.

The program changes the LED states in different sequences, creating multiple chasing and running-light effects.

Code




/*
  Arduino UNO LED Chaser

  Components:
  - Arduino UNO R3
  - 8 x LEDs
  - 8 x 220 ohm resistors
  - Breadboard
  - Jumper wires
  - USB Cable
  - OTG Cable
  - Android Phone
  - Arduinodroid App

  Author: Circuit Creation RN
*/

int leds[] = {2, 3, 4, 5, 6, 7, 8, 9};

int totalLEDs = 8;

void setup() {

  for (int i = 0; i < totalLEDs; i++) {
    pinMode(leds[i], OUTPUT);
  }

}

void loop() {

  // EFFECT 1: Forward Running
  forwardChase();

  // EFFECT 2: Reverse Running
  reverseChase();

  // EFFECT 3: Knight Rider Scanner
  scannerEffect();

  // EFFECT 4: All LEDs Flash
  flashEffect();

  // EFFECT 5: Wave Effect
  waveEffect();

  delay(300);

}


// --------------------------------
// FORWARD CHASE
// --------------------------------

void forwardChase() {

  for (int i = 0; i < totalLEDs; i++) {

    digitalWrite(leds[i], HIGH);

    delay(100);

    digitalWrite(leds[i], LOW);
  }

}


// --------------------------------
// REVERSE CHASE
// --------------------------------

void reverseChase() {

  for (int i = totalLEDs - 1; i >= 0; i--) {

    digitalWrite(leds[i], HIGH);

    delay(100);

    digitalWrite(leds[i], LOW);
  }

}


// --------------------------------
// KNIGHT RIDER SCANNER
// --------------------------------

void scannerEffect() {

  // Forward
  for (int i = 0; i < totalLEDs; i++) {

    digitalWrite(leds[i], HIGH);

    delay(80);

    digitalWrite(leds[i], LOW);
  }

  // Reverse
  for (int i = totalLEDs - 2; i > 0; i--) {

    digitalWrite(leds[i], HIGH);

    delay(80);

    digitalWrite(leds[i], LOW);
  }

}


// --------------------------------
// ALL LED FLASH
// --------------------------------

void flashEffect() {

  for (int x = 0; x < 3; x++) {

    for (int i = 0; i < totalLEDs; i++) {
      digitalWrite(leds[i], HIGH);
    }

    delay(150);

    for (int i = 0; i < totalLEDs; i++) {
      digitalWrite(leds[i], LOW);
    }

    delay(150);
  }

}


// --------------------------------
// WAVE EFFECT
// --------------------------------

void waveEffect() {

  for (int i = 0; i < totalLEDs; i++) {

    digitalWrite(leds[i], HIGH);

    if (i > 0) {
      digitalWrite(leds[i - 1], LOW);
    }

    delay(120);
  }

  for (int i = totalLEDs - 1; i >= 0; i--) {

    digitalWrite(leds[i], HIGH);

    if (i < totalLEDs - 1) {
      digitalWrite(leds[i + 1], LOW);
    }

    delay(120);
  }

  // Make sure all LEDs are OFF
  for (int i = 0; i < totalLEDs; i++) {
    digitalWrite(leds[i], LOW);
  }

}

Code Explanation

The program configures Arduino digital pins 2 to 8 as outputs. The digitalWrite() function is used to turn each LED ON or OFF, while delay() controls the speed of the chasing effect.

Different LED sequences are programmed to create multiple running-light effects. The Arduino continuously repeats these patterns, producing a dynamic LED chaser animation.

Project Working

After uploading the program, the Arduino UNO controls the 8 LEDs one by one according to the programmed sequences. The LEDs continuously move in different patterns, creating the LED chasing effect.

Why may the LEDs look dim?

When the Arduino is powered directly through a phone's OTG connection, the phone may limit the available USB current. When multiple LEDs are active, the available power can become insufficient and the LEDs may appear dim.

For brighter and more stable operation, use a suitable regulated power supply for the Arduino and LED circuit while keeping all grounds connected together.

Common Mistakes

  • LED polarity connected incorrectly.
  • Missing or incorrect resistor values.
  • Wrong Arduino pin numbers in the code.
  • Loose breadboard connections.
  • OTG cable or USB connection problem.
  • Insufficient power when many LEDs are ON.

FAQ

How many LEDs are used?

This project uses 8 LEDs connected to Arduino digital pins 2 to 9.

Can I create different LED effects?

Yes. You can program different sequences such as forward chasing, reverse chasing, bouncing effects, and alternating patterns.

Why are my LEDs dim when using OTG?

The phone's OTG port may limit the available current, especially when several LEDs are operating. A suitable external regulated power supply can provide more stable power.

Can I upload the code without a laptop?

Yes. You can use the Arduinodroid app with an Android phone and OTG cable to upload the program.
