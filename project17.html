Arduino UNO LED Chaser

This Arduino UNO LED Chaser project creates multiple running-light effects using 8 LEDs. The LEDs turn ON and OFF in different sequences to produce a colorful chasing animation. This beginner friendly project demonstrates Arduino digital output control, LED sequencing, and basic programming without using complex components.

Components Required

  • Arduino UNO R3
  • 8 × LEDs
  • 8 × 220Ω Resistors
  • Breadboard
  • Jumper Wires
  • Arduino USB Cable
  • OTG Cable
  • Android Phone
  • Arduinodroid App

Circuit Connections

Step 1 – Connect the LEDs

Connect the 8 LEDs on the breadboard in a straight or arranged pattern. Keep the LED polarity correct.

Step 2 – Connect LED Resistors

Connect one 220Ω resistor in series with each LED to limit the current and protect the LEDs.

Step 3 – Connect LED Positive Terminals

Connect the positive leg (anode) of each LED through its 220Ω resistor to Arduino digital pins 2 to 9.

Step 4 – Connect LED Negative Terminals

Connect the negative leg (cathode) of every LED to the Arduino GND.

Step 5 – Connect the Arduino

Connect the Arduino UNO to your Android phone using a USB cable and OTG cable.

Step 6 – Open Arduinodroid

Open the Arduinodroid app, create a new sketch, and paste the LED Chaser code.

Step 7 – Upload the Code

compile and upload the program. After uploading, the LEDs will start running through the programmed effects.

Circuit Explanation

The LED is connected to Digital Pin 12 of the Arduino UNO through a current-limiting resistor. The Arduino repeatedly turns the pin HIGH and LOW, making the LED blink at one-second intervals.

The program is uploaded directly from an Android phone using the Arduinodroid app and an OTG cable, eliminating the need for a laptop or desktop computer.

Code




/*
 Arduino LED Blink with Mobile Phone

 Components:
 - Arduino UNO R3
 - Arduino Cable
 - LED
 - OTG Cable

 Author: Circuit Creation RN
*/

int ledpin = 12;

void setup() {

  pinMode(ledpin, OUTPUT);

}

void loop() {

  digitalWrite(ledpin, HIGH);
  delay(1000);

  digitalWrite(ledpin, LOW);
  delay(1000);

}

Code Explanation

The setup() function runs once and configures Digital Pin 12 as an output. Inside the loop() function, the LED is turned ON for one second using digitalWrite(HIGH), then turned OFF for one second using digitalWrite(LOW). This process repeats continuously, creating a blinking LED effect.

Project Working

After uploading the program through the Arduinodroid app using an OTG cable, the Arduino UNO executes the code continuously. The LED connected to Digital Pin 12 blinks every second, demonstrating the basic operation of digital output control.

Learning Outcome

Common Mistakes

  • Wrong LED polarity.
  • Incorrect pin number in the code.
  • OTG cable not detected.
  • Board or COM port not selected correctly.
  • USB cable without data support.

FAQ

Can I upload Arduino code without a laptop?

Yes. You can upload code using the Arduinodroid app and an OTG cable with an Android phone.

Why is my LED not blinking?

Check the LED polarity, wiring, board selection, and ensure the code is uploaded successfully.

Which Arduino board is used?

This project uses the Arduino UNO R3.
